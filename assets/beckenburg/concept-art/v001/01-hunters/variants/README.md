# Hunter Alternative Model Variants — Original PNG Source Art

Three full-resolution concept sheets provide **four distinct character model variations each** for Cleric, Observer, and Demonologist. They are intended as alternative body, costume, silhouette and age/style designs, not merely recolors of one model. Use the approved first Beckenburg ensemble and hard PS1-era guide as production style authority. No source image here is an implemented rig/mesh or a proof that variants are selectable in the Java game.

All original 1448 × 1086 PNGs are preserved byte-for-byte. Verify original and remote SHA-256 and Git blob SHA-1 using `manifest.json`. The source Drive copies are maintained under the Beckenburg Concept Art Bridge / Gender Variants v001 folder. The earlier muted blue/blonde *hair-only* proposal is not a replacement for these body/costume variants; future bright color choices should be independent cosmetic parameters.

| Role | Variant silhouettes |
|---|---|
| Cleric | Veteran Cleric (male); Field Cleric (female); Novice Cleric (male); Matriarch Cleric (female) |
| Observer | Field Investigator (female); Documentarian (male); Tech Specialist (female); Senior Analyst (male) |
| Demonologist | Field Scholar (male); Occult Investigator (female); Young Provoker (male); Elder Ritualist (female) |

**Implementation contract:** Each variant receives an explicit stable character model ID, first-person arm rig and third-person mesh, texture atlas, collision/animation compatibility and preview in character selection. The role equipment and abilities do not change with model choice. Hair dyes, including saturated bright hues, are a separate future customization layer.
