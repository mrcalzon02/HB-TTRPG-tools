# Sources and attribution

Prepared 7 October 2026 for the HB-TTRPG SS13–SS14 conversion record.
Tyson, Hamburg and Ourang originate from the owner's 2019 TGMC fork at
0561be01eb281e44787e46af55cd0f13478c3e9a, restored against main TGMC at
d17228095d2bbc94359acaf7421119a60c672261. Vapor is that upstream layout.
SS14 ports use native prototypes from 07c0caa76bf941d2a5ed53b827c0bc25f16eb162.
Original attribution/license notices accompany this bundle under licenses/.
Native SS14 graphics and other upstream game resources are downloaded in their
original repository, rather than bundled as a new asset collection.
These scripts install pinned versions, not future upstream revisions.
