# Kaysender Wiki Data

This folder stores seed wiki entries for the Kaysender hypertext campaign operations layer.

## Files

- `entries.json` — current seed wiki data.
- `../schemas/wiki-entry.schema.json` — schema for individual wiki entries.

## Current purpose

The wiki data is meant to support cross-linking between:

- Setting lore.
- Tools.
- Utilities.
- Generators.
- Open d20 conversion work.

Each entry should use stable IDs so tool outputs, generator cards, future campaign notes, and other wiki entries can link to it reliably.

## Conversion note

Do not paste large manuscript passages directly into wiki entries. Keep entries concise, operational, and source-safe. Rules-facing mechanics should remain separate until converted into open d20-compatible language.
