# Wiki Source Lore Passes 28-30

These passes improve searchability for source material that was previously preserved only in omnibus overview entries.

- Pass 28 creates dedicated pages for five potion guilds.
- Pass 29 creates dedicated pages for nine mercenary companies.
- Pass 30 creates dedicated pages for seven cultural signals and the luxury beacon group.

The original overview entries remain category hubs. Edition-specific potion effects remain isolated in `mechanics-legacy` sections.
