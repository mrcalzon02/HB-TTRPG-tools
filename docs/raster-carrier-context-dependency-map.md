# Raster Carrier Context Dependency Map

Diagnostic Pipeline 0.3 keeps raster **Asset Presence**, **unresolved evidence**, and **carrier context** conceptually separate. This file records which retained measurements are eligible for research as non-circular carrier context and which remain detector-derived evidence.

The distinction is methodological, not a claim that carrier-context measurements are automatically safe correction variables. Carrier-context candidates still require development/holdout replication and within-family analysis before any production use.

## Detector-derived measurements

These measurements are derived directly from the RS/SPA payload-estimator or estimator-agreement structure that also drives current raster diagnostic flags. They may be useful evidence, but they MUST NOT be treated as independent carrier normalization context.

| Measurement | Classification | Reason |
| --- | --- | --- |
| `lumaEstimatorAgreement` | `detector-derived` | Direct agreement measure between RS/SPA estimator outputs. |
| `lumaEstimatorSpread` | `detector-derived` | Direct spread between RS/SPA payload estimates. |
| `crossChannelPayloadRange` | `detector-derived` | Cross-channel payload-estimate range; materially adjacent to `cross-channel-payload-divergence`. |
| `crossChannelEstimatorAgreementRange` | `detector-derived` | Cross-channel range of estimator-agreement values. |

A high correlation between these fields and the current unresolved score is partly expected because the score is constructed from flags generated by the same detector family. Such correlation is not independent evidence that the carrier itself is intrinsically difficult.

## Carrier-context candidates

These retained measurements are not current unresolved-flag predicates and are eligible for **research-only** carrier conditioning analysis.

| Measurement | Classification | What it describes |
| --- | --- | --- |
| `lumaResidualRoughness` | `carrier-context` | Mean local residual magnitude / spatial roughness. |
| `lumaResidualCooccurrenceEntropy` | `carrier-context` | Entropy of the residual co-occurrence matrix. |
| `lumaResidualDiagonalFraction` | `carrier-context` | Fraction of residual co-occurrences on the matrix diagonal. |
| `lumaResidualSymmetryError` | `carrier-context` | Asymmetry of residual co-occurrence counts. |
| `lumaLsbEntropy` | `carrier-context` | Entropy of the luma LSB sequence. |
| `lumaLsbOneFraction` | `carrier-context` | Fraction of luma LSB samples equal to one. |
| `lumaLsbTransitionFraction` | `carrier-context` | Transition rate in the luma LSB sequence. |
| `lumaPairChiSquare` | `carrier-context` | Pair-equalization chi-square feature retained independently from RS/SPA status. |
| `crossChannelLsbEntropyRange` | `carrier-context` | Spread of LSB entropy across R/G/B/luma views. |
| `crossChannelPairChiSquareRange` | `carrier-context` | Spread of pair-equalization chi-square across channel views. |
| `crossChannelResidualRoughnessRange` | `carrier-context` | Spread of residual roughness across channel views. |

These fields can still be affected by embedding. Calling them carrier context means only that they are not part of the current flag predicates being conditioned. Any future normalization must be trained from clean-carrier behavior and evaluated on untouched carrier instances.

## Required research discipline

A carrier-conditioning candidate must satisfy all of the following before production consideration:

- its cut point or model is derived from development carriers only;
- all derivatives of one carrier remain in the same development/holdout split as that carrier;
- holdout is evaluated using the unchanged development-derived rule;
- detector-derived measurements remain excluded from the independent-context candidate set;
- performance is inspected within carrier families as well as globally, so a family label proxy is not mistaken for a generally useful context feature;
- small within-family holdout samples are treated as descriptive rather than stable calibration estimates;
- no context rule may increase Asset Presence merely because the carrier appears difficult;
- any eventual production model must be independently versioned and must state its fitted corpus, uncertainty, and blind spots.

## Current status

The carrier-conditioning model remains research-only. `RASTER_UNRESOLVED_FLAG_WEIGHTS` remain `provisional-prior`, fitted cases remain 0, and unresolved evidence continues to affect Miss-Risk rather than Asset Presence.

The first global development/holdout conditioning study identified `lumaResidualRoughness` as a promising non-circular carrier-context feature, but within-family replication must be inspected before a normalization experiment is justified.

## Boundary

“Independent carrier context” in this project means **independent of the current unresolved-flag construction**, not independent of image content or embedding physics. A variable can be non-circular and still be a poor, family-specific, or confounded predictor. No feature becomes a production correction merely because it ranks highly in research.
