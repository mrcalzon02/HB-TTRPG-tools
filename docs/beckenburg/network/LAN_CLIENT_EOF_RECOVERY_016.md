# Alpha 2.3 — Network loss and ghost-view usability

The client now reports a single INFO|network connection ended event on normal TCP EOF as well as malformed/truncated remote input; deliberate local shutdown stays silent. The Swing lobby marks unexpected disconnection explicitly, closes orphan 3D views/streams, disables stale controls, resets role/room state, releases any local host listener, and permits a new Host LAN / Join IP attempt without restarting the program. Asynchronous connect attempts and event callbacks use a connection-generation guard to avoid callbacks from a superseded socket destroying the next session. Clicking Enter 3D World twice with an open ghost viewport now simply returns focus to that viewport instead of dereferencing an absent hunter panel.

LanClientDisconnectTest tests real TCP clean EOF, exactly-once notification and deliberate local-close suppression; it is added to both Java 17 scripts. LanLobbyReconnectGuiTest exercises Swing join → server close → stale-controls-disabled → rejoin through a second host, while LanGhostGuiTest includes a repeat-open regression. GUI tests require an actual display/Xvfb and are not invoked by the headless build scripts. Full clean-source build, Windows controller/hardware, and four-client end-to-end testing remain unverified.
