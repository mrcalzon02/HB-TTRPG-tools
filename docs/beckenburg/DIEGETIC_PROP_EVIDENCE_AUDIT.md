## Physical display contract

1. A tool's display is attached to its physical model/face, not a floating HUD readout. LED bar, numeric meter, digital temperature and frequency/camera screens reflect the **last actual validated measurement**, not decorative timer animation.
2. Display ownership: render observed values from the server's measurement event. Only approved data (numerical value, unit, status, age/battery/signal) enters the display; never leak the hidden species, anchor, or private hunter information to a ghost.
3. **EMF 1–10** normally. EMF **7–10** during an actual local ghost action can be positive. A real suppression event can instead produce **0** on a working meter. A displayed **0** during ghost-caused electromagnetic suppression is a reading immediately: log it without any repeat or verification quota. Investigators may independently compare it against other readings when identifying the ghost. A single low EMF, inactive reader, ordinary baseline, battery failure or blocked radio does not count.
4. **Cold below 0°C / 32°F** and **hot at least 90°F / 32.22°C** are separate paranormal temperature signatures; common seasonal, heating and weather effects alone are not proof. Meter readouts should support player-selected °C/°F; the existing source currently reports both.
5. **Ghost writing is authored into the physical book after placement and a real eligible ghost action in its room.** Display distinct layers: CHILD_DRAWINGS (crude little figures/houses/eyes), FRANTIC_SCRAWLS (crossed-out and overlapping marks), RITUAL_CIRCLES (concentric glyphs/geometry). The subtype is evidence detail; do not code each subtype as a unique species identifier. Book must remain inspectable and log actual observed style. Implement page-art decal/dynamic texture over the selected book mesh after UV face confirmation.
6. Controls for placing/retrieving/inspecting equipment should work when aimed at real nearby meshes. Current initial LAN writing-book command accepts host-validated **room** presence, but lacks a position-specific rendered/glb book instance and refined pickup targeting. Do not count it as a completed in-world prop.
7. Every accepted tool operation that yields a measurement produces a time-stamped investigator/room/device/value/outcome entry in the shared casefile. **Even ordinary background, no UV trace, zero EMF and repeated samples are actual readings. Non-ghost activity must never create a paranormal mark or event.** There is no automatic confirmation state: logging a measurement and an investigator interpreting it are separate actions. The existing LAN history is a bounded **2048 entries** (was 32); if a match overflows, oldest observations drop. A persistent/exported full-session log remains a future gate.
8. Book, camera, UV and sensor measurements must be added to the same logger; never force them through fake EMF/thermometer events to get a casefile entry. Keep ghost and hunter evidence channels private, and avoid duplicate evidence awards from the same physical event.
