## Visual characteristics worth reusing

1. PlayStation-era low-poly environments with limited texture resolution, colored fog, visible dithering, conservative lighting and camera framing.
2. Grim, readable menu geometry: thin bevels, weathered metal/stone, restrained crimson or cold blue accents.
3. Distinct atmospheric establishing shots for scene loading, with enough negative space for runtime UI text.
4. Cohesive 3D item portrait lighting and consistent square framing — but any shipped items must be drawn from their own game's actual art/model catalog.
5. Separately rendered and editable UI text. **Never embed generated titles, fake symbols, incorrect item labels, UI controls, or platform trademarks into shipping assets.**
