What it does

Captures original 3D model and texture responses from a selected browser tab, with an additional limited WebGL geometry recording fallback. The manifest identifies it as 3D Capture 0.1.1, with extension ID 3d-capture@local.tools and a minimum Firefox version of 140.

Manual temporary installation

  1. Download and extract the ZIP.
  2. In desktop Firefox, open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on and select the extracted manifest.json.
  4. Open a model viewer, select the 3D Capture toolbar icon, then follow its capture instructions. Temporary installs are unloaded when Firefox closes.

The original ZIP contains META-INF signature files, but this repository has not independently verified permanent-install signing. Review the extension's broad website and network permissions before installation.

README, security notes and details

Scope

No private models, session cookies or downloaded user assets are included in this package. The extension is intended for content you are authorized to retrieve. Its captured exports may contain sensitive source URLs and should be reviewed before sharing.
