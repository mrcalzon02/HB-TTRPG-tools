Collection boundaries

The dashboard is intentionally designed to provide useful site operations data without exposing individual visitors.

No public IP listA collector may use a source address to produce a rotating anonymous uniqueness estimate, then discard the raw address immediately.
Country-level geographyNo street, city, precise coordinate, or residential-location information is required.
No form contentsCharacter names, campaign notes, search text, generated records, and user-entered values are excluded.
No cross-site advertising IDThe tracker uses a first-party random identifier only for repeat-visitor and session estimates.
Privacy signals respectedGlobal Privacy Control and browser Do Not Track disable the tracker when enabled.
Finite retentionThe intended aggregate-retention window is 90 days unless the configured collector establishes a shorter period.
