A locally executed copy of the shared Shadowrun and Blacklight Binary Cube workspace.

Offline Local storage Full-depth JSON keys Six-face collision-free 1024 × 1024 grids

Desktop edition

The same Binary Cube engine, without requiring the website.

This application runs entirely on the local computer. Files, JSON keys, packages, passphrases, and working data are not sent to a server by the application.

Important: the Binary Cube permutation remains experimental tabletop obfuscation. Authenticated envelopes use standard browser cryptography, but the Binary Cube algorithm itself must not be represented as production-grade encryption. Every accepted key retains exact depth values from 0 through gridSize−1 and must remain collision-free from all six cube directions.
