# Original Project Audio

The audio files in `Effects/` and the sibling `../Music/` directory are original project resources supplied by the repository owner for inclusion and distribution with the Barotrauma World Simulation Toolbox.

They are not donor files extracted from a Barotrauma installation. Donor-game audio remains subject to the local-installation boundary documented in `docs/donor-assets.md` and must not be committed here.

These resources are retained for the planned opt-in desktop audio service. Their presence does not imply that playback, mixing, volume, or lifecycle integration is complete.
