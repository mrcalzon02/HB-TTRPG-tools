# Packaged Fallback Artwork

These PNG files are original neutral fallback artwork created for the Barotrauma World Simulation Toolbox.

They are not extracted from Barotrauma and do not contain Barotrauma game assets.

They are distributed under the repository's project license and exist so the desktop application remains usable when a donor Barotrauma installation is unavailable, moved, incompatible, or intentionally disabled.

Files:

- `fallback-station.png`
- `fallback-vessel.png`
- `fallback-fauna.png`
- `fallback-geology.png`
