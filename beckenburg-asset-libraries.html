Original CC0 asset libraries

Reusable PSX scenery built for Beckenburg. Every asset on this page—including its embedded textures—is original and released under CC0 1.0 Universal. Use, modify and redistribute it, including commercially; attribution is not required.

Each model has a preserved Clean version and a separate Worn version. Both have identical geometry, UVs, metre scale and pivots. The worn set is used in the game. Download individual GLBs or editable Blender sources below. Each library ZIP also contains a native Blender Asset Browser library, previews, dimensions, hashes and its CC0 license. Purchased archive assets used inside the game are outside these downloads.
