Install on Windows 10/11

  1. Download the Windows x64 ZIP and extract the entire folder.
  2. Open Install.cmd in the extracted SimpleSoundManager folder. The prebuilt app includes its runtime; Python is not required.
  3. For routing and EQ, use Windows audio setup in the app to install the signed VB-CABLE driver, approve its Windows administrator prompt, then restart Windows.
  4. Reopen the manager and choose outputs with Play here. Routing starts automatically unless you disable it.

The manager installs for your user account. VB-CABLE is separately licensed donationware from VB-Audio; it is downloaded directly from the vendor and is not bundled. Quit the current manager from its tray before reinstalling the same version.

Install on Linux

Extract the source download, open a terminal in its sound-manager folder, and run bash install-linux.sh as your desktop user. Open Simple Sound Manager from the applications menu.

Requires Python 3.11+, pip/venv, pactl, libpulse, and a working Qt desktop with PulseAudio or PipeWire-Pulse. The installer downloads Python dependencies. Pure ALSA/JACK setups are not supported. Linux routing is implemented but still needs live hardware validation.

Keep it updated

Open Updates in the app or Check for updates in the tray. The optional startup check looks for stable GitHub Releases tagged simple-sound-manager-v; releases for other Foundry tools are ignored. Choose Update to download and verify the package, then Install and restart when you are ready to pause audio. Not now keeps your current version. The first move from 0.6.0 requires this download; subsequent versions can use the built-in updater.

Download hashes are published with every release. Core audio works offline, and checks can be disabled. Linux updates use the source installer and still need live hardware validation.

What the controls affect

EQ and delay process streams routed through the manager. Microphone processing affects the app’s Meter/Listen path; it does not yet provide a processed microphone to other voice applications. Use headphones for microphone monitoring.

Auto sync uses reported driver latency; Bluetooth may need manual adjustment. Surround layouts are PCM channel arrangements. Dolby bitstream encoding and Atmos object metadata output are not implemented. Apps with exclusive audio or a fixed output may bypass system routing.
