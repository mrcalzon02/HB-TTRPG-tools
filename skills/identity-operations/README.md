**SECURITY BOUNDARY.** This GitHub repository and the public Agent Skills site are not a private evidence vault. Never commit any subject's real names matched to home records, residential addresses, personal phone numbers or emails, relatives, DOB, verification materials, case-specific URLs or screenshots containing personal identifiers, form submissions, correspondence, cookies, tokens or private findings. Public git history and CI logs are persistent. These templates are intentionally unfilled. Make any real case copy **outside this checkout** in an independently chosen encrypted, access-controlled vault. A .gitignore rule alone is not encryption. Do not use a publicly accessible GitHub issue to store case details.

Public outputs: plan, workflow definitions, blank templates, deliberately approved professional pages, and non-identifying aggregate progress only. No real opt-outs, publishing, or third-party contacts have been authorized by the creation of these files.
