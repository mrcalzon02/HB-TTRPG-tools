Deterministic shared engine

One topology engine, multiple setting adapters.

The module-map and alien-vessel generators use the same seeded semantic graph, room placement, corridor routing, door/socket, interdeck connector, pruning, and validation implementation. Module maps adapt the result to the existing tile editor schema; alien vessels preserve semantic compartment and pressure-zone data.
