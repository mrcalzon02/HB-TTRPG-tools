Deterministic shared engine

One topology engine, multiple setting adapters.

The module-map and alien-vessel generators use the same seeded semantic graph, room placement, corridor routing, door/socket, interdeck connector, pruning, and validation implementation. Vessels add a second derived layer that wraps the interior in a continuous selectable hull: connected skin, oval, capsule, rectangle, square/cube, or circle/cylinder, with adjustable hull tightness.

Acceptance gates

DeterministicSame seed and semantics produce the same topology and geometry.
ConnectedAll semantic destinations remain reachable.
SeparatedPlaced rooms cannot geometrically overlap.
Hull-containedEvery occupied interior cell remains inside one continuous vertically connected outer skin.
