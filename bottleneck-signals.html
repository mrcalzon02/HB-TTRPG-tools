About this extension

Bottleneck Signals v0.4.1 is an experimental Firefox add-on built primarily for ChatGPT conversations on chatgpt.com, with secondary best-effort support for Claude on claude.ai. It displays a compact G or C inside a tab favicon status circle: green while responding, flashing orange after completion, red for detected errors or connection interruptions, and gray when state cannot be classified. A quiet-generation timer can flag suspected stalls. Orange flashing is enabled by default and can be disabled in the extension popup.

It is strictly passive: it does not send prompts, retry, stop, navigate, schedule, or trigger model requests. It does not intentionally collect or transmit conversation history.

Independence: This experimental application is independently developed and is not affiliated with, sponsored by, endorsed by, or officially supported by OpenAI or Anthropic. Brand names are used only to describe compatibility.

Manually install in Firefox — temporary testing build

  1. Save the Bottleneck Signals ZIP from the project distribution and extract it to a normal folder.
  2. Open Firefox and enter about:debugging#/runtime/this-firefox in the address bar.
  3. Select Load Temporary Add-on and choose manifest.json from the extracted folder.
  4. Reload any open ChatGPT or Claude tabs so the extension can observe their visible interface controls.
  5. Open the Bottleneck Signals toolbar popup to inspect per-tab states, toggle orange flashing, and adjust the inactivity warning threshold.

Important: Temporary add-ons are unloaded when Firefox exits. Repeat these steps after each browser restart. Normal permanent installation requires Mozilla signing; do not bypass Firefox signing safeguards.

Indicator key and troubleshooting

  • Green G/C: generation detected.
  • Flashing orange G/C: completed and awaiting user input.
  • Red G/C: detected error, restriction, or interruption. This is a warning; it never automatically retries.
  • Gray G/C: unknown, unsupported, or unsettled page state.
  • Suspected stall: active response with no observable content progress for the configured interval, not proof that backend work has stopped.

If a status stays gray, reload the tab and examine the extension popup. Browser UI changes may require updated detectors. Claude may override the favicon with its own; Claude support is experimental. The extension is designed to remain lightweight alongside conversation-truncation extensions.
