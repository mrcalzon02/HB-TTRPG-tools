CubeChat

First functional milestone: two local independent participants using different A→B and B→A cube keys. This is a local exchange test, not an Internet messenger.

Experimental local prototype. The Latin-cube permutation is not a secure cipher. This prototype additionally authenticates and encrypts each cube-encoded message with AES-256-GCM. It uses the browser's secure random API, not a certified external physical random source. Keys are kept only in page memory, and both participants are simulated locally.
