SuperPosition Reader

A private, independent offline document reader and voice narration studio.

Foundry HomeSoftware

Experimental prototype v0.1 — Windows

Import. Narrate. Follow the words. Keep the recording.

SPR is being built as a standalone Windows desktop reader, stored as its own source module inside HB-TTRPG-tools. The prototype imports selectable-text PDFs, TXT, Markdown and DOCX; synthesizes WAV narration using installed Windows SAPI voices; highlights the sentence during playback; and keeps an offline, resumable audio archive.

Not yet complete: custom neural voice cloning, original PDF page view, EPUB, OCR, word-level synchronization, full audiobook chapter exports, and a packaged executable installer. These are tracked development milestones, not released features.

Getting started on Windows

Clone or update HB-TTRPG-tools locally. Python 3.10+ is required for this source-stage installer.

powershell -NoProfile -ExecutionPolicy Bypass -File .\software\superposition-reader\install-windows.ps1 -RunAfterInstall

The script installs only Python dependencies into a private application environment and creates a Start Menu shortcut. It does not silently install AI models.

Voice profiles and personal recordings

SPR's voice architecture is intended to support privately archived user-authorized samples, including natural and dramatic narrator styles. The current prototype deliberately uses available Windows SAPI voices while the local neural engine and voice-profile importer are developed and tested.

Personal audio recordings, downloaded books, trained voices and generated narration must stay outside the public repository.

Audiobook workflow

Text is divided into manageable sentence chunks, which are synthesized and cached on disk. Generated chunks are reused when reopening a document. Users can play, pause, skip, change playback speed and volume, or export a single WAV when all chunks exist.

Timing is sentence-level in this prototype. Later versions will map word timestamps back to the original PDF or EPUB layout.

Engineering milestones

  1. Verify Windows installation, narration, cache recovery and reflowed highlighting on actual hardware.
  2. Implement original PDF page rendering, EPUB and scanned-PDF extraction.
  3. Integrate local Qwen3-TTS / Chatterbox voice cloning using authorized personal samples.
  4. Improve speech prebuffering, timestamp alignment, re-generation and quality controls.
  5. Export chapter audio, FLAC/M4B and deliver a self-contained Windows installer.
