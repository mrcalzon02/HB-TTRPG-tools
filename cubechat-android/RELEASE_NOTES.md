# CubeChat Android 0.1.1

Android version code: 2

- CubeChat checks for Android updates when it opens with internet access. The update notice shows the installed and available versions and lets you review the release notes before opening the signed APK in your browser.
- Choose **Pairing → Check for updates** to check immediately. Releases and prereleases qualify when their Android build number exceeds the installed build. You choose when to download and confirm the installation in Android.
- You can install this version over CubeChat 0.1.0 using the original signing identity. Existing chat keys, history, and queued messages stay in the app when you choose **Update** in the Android installer.
- New installations can still import the actual communication keys from a single QR scan while the other phone is offline. Messaging works over local Wi-Fi, Wi-Fi Direct, Bluetooth Classic, and manually configured local relay phones.

Download **CubeChat.apk** on the phone and open it from Downloads. Android 8.0 or newer is required.
