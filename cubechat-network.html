CubeChat — Address & Port

LAN development mode. Only encrypted envelopes are transported; the relay does not exchange keys. The initial channel bundle contains both symmetric secrets and must be handed to the other participant through an already trusted private method. Plain HTTP exposes network metadata, permits denial of service and active packet interference, and gives no server authentication. Do not use this version for sensitive messages or over the public Internet.

Directional cube keys

On device A, generate and save a channel bundle. Transfer it privately to B; import the identical bundle on both devices. It is secret key material, never send it through CubeChat's relay.

Public demonstration keys are preloaded. Both directions use fixed, published test-only material. Anyone can decode or forge demonstration messages. Never transmit confidential information with these keys.

Keys remain in this page's memory only; reimport after reloading. The imported secret is used to reconstruct the established Latin-cube matrix independently on each client.

Import preconfigured client package

Import the JSON package received privately from your host. Its settings automatically select your role, host, port and directional key pair. The package contains secret key material.

Package contents remain local; they are never uploaded to the CubeChat relay.
