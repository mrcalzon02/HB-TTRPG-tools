Host-sandbox · Python + Pillow + CSV

One pixel can equal one battlefield cell.

The authoritative state is stored as integer grid coordinates in CSV. The PNG is a deliberately primitive diagnostic projection. The required lowest-common-denominator render is exactly 1 pixel = 1 grid cell; larger previews use nearest-neighbor scaling of the same raster.

Spatial contract

Authoritative state

battlefield_maps.csv, battlefield_tokens.csv, battlefield_terrain.csv, and battlefield_effects.csv. Stable token IDs link battlefield representations to campaign entities.

Primitive rendering

Flat RGB cell colors only. No required fonts, icons, textures, SVG, canvas, WebGL, browser, or network assets. Separate composite, terrain, effects, and occupancy rasters are supported.

Human correction

“Left two” mutates dx=-2; “up one” mutates dy=-1. Structured state changes first, then the preview is regenerated. The previous PNG is never the source of truth.

Spatial queries

Placement, relative movement, range/proximity, nearest-footprint distance, effect overlap, map-bound validation, collisions, and low-resolution rendering are exposed by the portable Python helper.

Rules boundary

Generic grid, Manhattan, and Euclidean geometry do not silently replace a tabletop system’s movement, diagonal, reach, cover, line-of-sight, or area-template rules. Use explicit affected-cell sets when an authoritative rules engine has already resolved a template.
