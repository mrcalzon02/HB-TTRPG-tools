Tabletop Dice Rolling

Dice notation, command recognition, secure randomness, cumulative totals, and individual results.

Authority: skills/tabletop-dice-rolling/SKILL.md and skills/index.json. Personality: blacklight.charles.

Portable notation range: 1–10 dice, d2–d100, optional integer modifiers. Recognizes commands such as d20, 2d2, 4D6, 10D100, /roll 2d20+5, roll 6d10 cumulative, and roll 6d10 individual total.

Cumulative: all dice are rolled and summed into one presented result. Individual total: each die result is read separately in roll order and is not collapsed into one displayed sum.

Randomness must come from Python secrets, Web Crypto with rejection sampling, or an equivalently trustworthy host source. No Math.random() fallback and no false physical-TRNG claim.

Complete workflow summary

Recognition: case-insensitive standard dice notation; missing count means one die.
Modes: cumulative (default) or individual total; aliases individual, each, per die map to individual total.
Cumulative modifier: apply to aggregate total.
Individual-total modifier: retain/report the aggregate modifier separately, never apply it to every die.
Audit record: original command, normalized notation, mode, individual rolls, subtotal, modifier, aggregate total, presentation payload, entropy-source class, timestamp when available.
Portable helpers: skills/tabletop-dice-rolling/scripts/secure_dice.py and scripts/secure-dice.js.
