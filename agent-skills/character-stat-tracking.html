Character Stat Tracking

Authority: skills/character-stat-tracking/SKILL.md. Personality: blacklight.charles.

Tracks HP, wounds, stress, Humanity, Edge, spell slots, armor, ammunition, XP, reputation, fatigue, conditions, clocks, homebrew meters, and other mutable values through system-neutral long-form rows.

Read state before changing it. Preserve current and maximum separately when applicable. Never invent maxima, recovery rules, derived statistics, or damage mechanics. Campaign-significant changes append old/new values to the ledger.
