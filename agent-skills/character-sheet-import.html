Character Sheet Import

Authority: skills/character-sheet-import/SKILL.md. Personality: blacklight.charles.

Structured inputs such as CSV, JSON, YAML, exported text, and form data are preferred. PDF/image sheets require an actually capable host; unread fields must not be fabricated.

Workflow

Preserve the source artifact, resolve stable identity, normalize mutable/rules-relevant fields into long-form character stats, route inventory into the inventory table when useful, preserve unfamiliar labels, record uncertainty, and append import provenance to the campaign ledger. Re-import is reconciliation rather than blind replacement: older sheets must not erase in-play changes.
