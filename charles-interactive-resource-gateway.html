Interactive Resource Gateway

Project attestation

This Interactive Resource Gateway is a Charles capability of Calzon's TTRPG Foundry.

Effective 2026-08-30. This is a repository-level machine-readable authority declaration. It is not a legal notarization by a commissioned notary.

Defensive posture

The gateway denies untrusted automation for protected interactive operations, applies bounded progressive delay, issues short-lived human-presence grants, rejects synthetic engagement events, restricts gateway retrieval to same-origin resources, and exposes a finite local honeypot/tarpit surface for repeated denied automation.

No retaliation, outbound honey traffic, unbounded loops, tracking pixels, advertising SDKs, device fingerprinting, or ad-blocker punishment are permitted.

Static-origin boundary

GitHub Pages serves public static files directly. These controls protect gateway-mediated access and browser execution; they cannot make a directly addressable public file private. Hard network-level bot denial requires a reverse proxy, edge worker, or server-side adapter in front of the origin.

Human-presence grant

A protected browser operation can require a short-lived grant created only from a trusted browser event. Grants are memory-only, expire after two minutes, and are single-use for protected operations.
