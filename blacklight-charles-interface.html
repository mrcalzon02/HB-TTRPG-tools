Deployment architecture

Seven standard Charles facility-integration layers.

Every deployment starts with the full stack available for tailoring. Clients may enable only the layers that match their power budget, compliance posture, building systems, database maturity, and operating environment.

Layer 01voice

Room Voice Console

Single-room Charles control station for reception desks, dispatch rooms, secure conference spaces, or executive offices.

  • Wake phrase and push-to-talk profiles
  • Local speech recognition and response voice
  • Operator prompt logging and session labels
Layer 02documents

Document and Policy Vault

Retrieval layer for handbooks, manuals, SOPs, client binders, local forms, and controlled policy packets.

  • Versioned document indexes
  • Source-grounded response posture
  • Client-defined redaction and citation rules
Layer 03workflow

Workflow and Ticket Router

Routes voice requests into maintenance, HR, security, compliance, payroll, records, and client-support workflows.

  • Checklist generation
  • Handoff queues
  • Manager approval gates
Layer 04facility

Facility Systems Bridge

Optional interface boundary for building status, room schedules, visitor intake, access reports, and non-dangerous facility telemetry.

  • Read-only default posture
  • Escalation-first control design
  • Maintenance and incident summaries
Layer 05identity

Personalization and Role Profiles

Customizes Charles responses by department, role, authority level, communication style, and client vocabulary.

  • Persona tone windows
  • Department vocabulary packs
  • Role-scoped memory boundaries
Layer 06continuity

Continuity and Power Envelope

Adapts deployment behavior around power limitations, offline operations, degraded network states, and emergency staffing.

  • Low-power answer modes
  • Local cache discipline
  • Emergency procedure surfaces
Layer 07enterprise

Enterprise Command and Audit

Multisite governance layer for audit trails, deployment telemetry, change review, compliance exports, and executive reporting.

  • Audit officer review console
  • Incident replay summaries
  • Cross-site deployment dashboards
