## Manual deployment
1. Obtain the approved private package from its established private deployment location.
2. Inspect the contained README and package type to determine the correct launcher or installer.
3. **Only if the package contains a Firefox WebExtension manifest:** extract the archive, visit `about:debugging#/runtime/this-firefox`, select **Load Temporary Add-on**, and choose its `manifest.json`. Reload target tabs as needed. Firefox unloads temporary extensions after restart.
4. **If it is a native application:** follow the private package's verified platform-specific launch instructions. Do not treat this Firefox procedure as a native-app installer.
5. Confirm permissions, source licensing, download permissions and local storage location before use.
