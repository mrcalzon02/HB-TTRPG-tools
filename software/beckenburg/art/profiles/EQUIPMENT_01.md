# Equipment Studies 01 — Cleric and Universal Starter Kit

The first sheet concentrates on **four hand-built low-poly silhouettes**. A universal detector set follows for Observer in the next batch. The SVG concept `equipment-01.svg` is an *editable shape reference*, not a 3D mesh or wired game item.

- **Ward token:** 12–36 triangles proposed. Bronze-framed octagonal marker with off-white inset fictional 3-line chevron; held close, wrist strap tether; muted warm white action feedback when an active ward is valid. Need scale in first-person and readable glow under 320×200.
- **Consecrated vessel:** 40–90 triangles proposed. Weighted, angular flask with thick stopper and distinct capacity window. Controlled contents with one simple tint; no glass refraction necessary. Must remain visible while sprinting/throwing.
- **Circle chalk / cord box:** 35–80 triangles proposed. Small rectangular battered tin, hinged lid, chalk packets and wound cord. Placed prop leaves a low-poly boundary loop; interaction surface and snap points must correspond to ritual zone socket validation.
- **Field EM detector:** 50–110 triangles proposed. Blocky handheld case with three large amber/green rectangular display blocks, single thumb actuator, lanyard and obvious top-end antenna. Readout values eventually derive exclusively from simulation events, not random UI decoration.

Color key: token brass #90754e / ivory #d4c6a3; flask slate #667c83; chalk box oxide #584137; EM device graphite #282d32 / olive screen #8bb285.

Study validation: distinguish each in inventory silhouette at 24×24, distinguish held-item from ghost prop, maintain reasonable grip dimensions and do not place all required clues in subtle color alone. Each tool definition later receives host-side range, battery/consumable, readout channels, environment interference and persistence rules.
