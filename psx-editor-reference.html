PSX-inspired Editor & Runtime Engineering

Five owner-supplied design studies are filtered for the actual Beckenburg Java 17 game and reusable editor suite. We preserve useful PSX presentation, but refuse historical hardware constraints that would damage modern gameplay, performance or accessibility.

Editor gold standard

Exactly the same game scene, lighting, collision, weather, assets, save state and runtime preview in editor and playtest. Stable IDs, typed inspector, layer hierarchy, gizmos, snapping, Undo/Redo, recoverable save, real playtest and diagnostic object jumps.

PSX level craft

Readable low-polygon geometry, compact textures, intentional camera/sightline composition, authored portals and room zoning, dense story-rich spaces, controlled fog and audio landmarks. Widescreen support and physically correct traversable basements, doors and walls are required. Real clipping defects must be repaired rather than celebrated as PSX authenticity.

Lighting integration

Unified LightingModule and SceneRenderer remain authoritative. Profiles may expose Gouraud interpolation, quantization, 4×4 dithering, vertex snap and UV warp. Fixture reach, diffusion softness, occlusion and changing doors must be measured and visually correct. Do not double-apply postprocessing or invent a global lighting priority per cell.

AI and navigation

Author real portal/waypoint metadata, validate stair links and door-driven route invalidation. Profile first; prefer bounded work and caching. The authoritative host preserves hearing through materials, ghost legal movement, action cadence, and AI/player ghost fairness. No omniscience, fake sight, arbitrary teleport recovery or artificial four-connection graph cap.

Interfaces and accessibility

Compact PSX-like menus, tactile selection, controller/D-pad plus mouse and keyboard, remappable controls and fast transitions; high-contrast and scalable text, subtitles and accessible controls. No simulated disc freezes or mandatory memory-card mechanics.

Current editor integration

The Java 17 Beckenburg editor includes a PSX GUIDE viewer and a manually invoked SCENE AUDIT for Castle geometry: it checks possible lamp/prop centre overlap with real authored walls, duplicate authoring IDs, and blocked spawn placements, with jump-to-object navigation. These are advisory hints, not proof of a complete mesh-intersection suite or general-purpose cross-game editor.
